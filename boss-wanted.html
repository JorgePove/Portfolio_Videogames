Boss Wanted

Original board game — Personal project

Project Name Boss Wanted
Type Board Game
Role Game Designer
Status In development
  • Personal project where I designed, balanced, prototyped and playtested a brand new board game, completely from scratch.
  • Boss Wanted is a board game for 2 to 6 players, where each player controls a monster and tries to run through a trap-filled obstacle course dungeon, while trying to trip over the other players, so they can reach the end first and become the new dungeon Boss.
  • Mod fully playeable on TableTop simulator.
